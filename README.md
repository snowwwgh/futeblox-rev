## 📱 Instalação

1. Baixe o arquivo `futeblox.apk`.
2. Abra o APK no seu dispositivo Android.
3. Caso o Android solicite, permita a instalação de aplicativos de fontes externas para o navegador ou gerenciador de arquivos utilizado.
4. Confirme a instalação.
5. Abra o Futeblox.
